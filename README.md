Made2Blast🚀
Made2Blast es un sitio web dinámico y moderno, diseñado para destacar con una estética visual atractiva y una experiencia de usuario fluida. Este proyecto está construido con HTML5, CSS3, y JavaScript puro, centrándose en el rendimiento y la adaptabilidad.

Características Principales
1. Preloader Personalizado
El sitio web cuenta con un preloader único y personalizado que simula un progreso de carga con un anillo giratorio y un logo animado. Muestra mensajes rotativos para mantener al usuario entretenido mientras se carga el contenido.

Animación de Carga: Un círculo de progreso animado y un logo que rota y flota.

Mensajes Dinámicos: Muestra una serie de mensajes informativos y de bienvenida que cambian cada 3 segundos, como "Hola, bienvenido a Made2Blast" o "Recuerda que puedes agendar una consulta gratuita via WhatsApp".

2. Diseño Responsivo y Estético
Made2Blast está optimizado para una visualización perfecta en cualquier dispositivo, desde computadoras de escritorio hasta teléfonos móviles.

Menú Hamburguesa: Un menú colapsable para una navegación limpia en dispositivos móviles.

Diseño Moderno: Utiliza una paleta de colores oscuros con acentos de azul brillante (--color-primary: #26baf5) y tipografía Segoe UI.

Efectos Visuales: Incluye un "shimmer" en el logo principal y efectos de brillo en los botones al pasar el cursor.

3. Experiencia de Usuario Interactiva
El sitio ofrece varias secciones interactivas y animaciones para mejorar la navegación y el compromiso del usuario.

Carrusel Automático: Un carrusel principal que presenta diferentes servicios (diseño de sitio web, tienda online, remodelado de marca) con transiciones suaves y efectos de acercamiento en las imágenes. Los usuarios pueden navegar por los servicios haciendo clic en las opciones correspondientes o usando los botones de navegación del carrusel.

Efecto Parallax: Un fondo dinámico que se mueve a una velocidad diferente a la del contenido, creando una sensación de profundidad. Este efecto se combina con partículas flotantes y un logo animado que brilla.

Carrusel de Imágenes Informativas: Una sección con un carrusel de imágenes que destacan los beneficios de tener una página web (como SEO eficiente, monetización con AdSense, etc.). Cada imagen tiene un pie de foto que se muestra al pasar el cursor.

4. Funcionalidades Adicionales
Botón Flotante de WhatsApp: Un botón de WhatsApp flotante en el lateral de la pantalla permite a los usuarios chatear con el equipo con un solo clic. Este botón se desliza completamente a la vista al pasar el cursor sobre él y tiene un efecto de "pop" al ser presionado.

Botón de Regreso al Inicio: Un botón de "Back to Top" aparece una vez que el usuario ha desplazado la página, permitiendo un regreso rápido a la sección de servicios.

Modal de Imágenes: Al hacer clic en las imágenes del carrusel informativo, se abre una ventana modal para ver la imagen en un tamaño más grande.
